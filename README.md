# Sivra — Sinos de Âmbar (beta)

Versão de teste para amigos. Jogue no navegador: https://llmartinsll04.github.io/sivra-beta/

- Funciona melhor no Chrome, Edge ou Firefox de computador (teclado e mouse).
- O progresso fica salvo no próprio navegador (não use aba anônima).
- Controles: WASD/setas para andar, Shift para correr, Espaço ou botão direito para atacar, E para conversar.

Feito em Godot 4.7.2. Fontes sob SIL Open Font License 1.1 (pasta `licencas/`): Pixeloid (GGBotNet),
Cinzel Decorative, Alegreya SC e Alegreya Sans.
